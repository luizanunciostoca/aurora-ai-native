# W02-A — Wave Evidence

## Scope

Identity Resolution Contracts & Runtime, reconciled on the accepted W02-B/W02-C main and integrated with the W02-00 PB1 publication barrier.

## Architecture invariants

- Reuses canonical W01 `IdentityId`, `TenantId`, `ActorRef`, `SubjectRef`, `CorrelationId`, `CanonicalError` and `ContractVersion`.
- Provider/external IDs never become canonical `IdentityId` values.
- Tenant mismatch fails closed.
- Unknown and ambiguous resolution fail closed.
- Expected identity kind mismatch fails closed.
- Resolution evidence requires `authorityGranted: false`.
- Equivalent records/request/clock replay deterministically.
- No Policy Engine, provider side effects, identity graph persistence, W03 persistence or later-wave intelligence logic is implemented.

## PB1 publication

Coordinator-owned publication exposes:

- `@aurora/contracts/identity-resolution`
- `@aurora/contracts/tenant-boundary`
- `@aurora/schemas/identity-resolution`
- `@aurora/schemas/tenant-boundary`
- `@aurora/schemas/consent`
- `@aurora/schemas/purpose`
- `@aurora/schemas/jurisdiction`

The existing consumer fixture was extended to resolve and exercise these supported public subpaths. Direct internal-source imports are not accepted as publication evidence.

## Workspace lock

The root npm v3 lockfile is coordinator-owned. It was regenerated by GitHub Actions with Node 22.16.0 and npm 10.9.2 using `npm install --package-lock-only --ignore-scripts`, producing the canonical `services/identity` workspace/link entries. The temporary regeneration workflow was removed before final validation.
